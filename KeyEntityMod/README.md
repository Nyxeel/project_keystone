# FirstMod (MVP A Scaffold)

Dieses Verzeichnis ist ein **MVP-A-Skeleton** für die Hytale-NPC-Mod (server-first, 1 NPC, 3 Marker). Es ist bewusst **minimal** und enthält vor allem **Java-Strukturen + TODOs**, damit die Implementierung sauber und in kleinen Schritten passieren kann.

## MVP A Ziel
- 1 Lumberjack NPC
- 3 Marker: bed/door/work
- Tagesablauf: Tag = Work, Nacht = Sleep
- Save/Load (JSON)

## Wichtiger Hinweis
Die Hytale-Server-API/Types sind hier als **Platzhalter** modelliert (z. B. `WorldId`, `Vec3`). Beim echten Einbau werden diese durch die realen Hytale-Klassen ersetzt.
